# 焦散光场虚拟仿真教学系统

## 项目简介

焦散光场虚拟仿真教学系统是一个基于 Web 前端技术的虚拟仿真平台，用于展示复杂相位调制后光线族与焦散结构的空间演化。该系统面向高等光学、计算成像与波前调控教学，以物理一致性优先为原则，帮助学生理解相位分布、梯度场和焦散形成之间的关系。

## 核心功能

- **相位模型选择**：支持多项式、艾里类三次、涡旋、锥面和平滑噪声等多种相位函数
- **动态参数控制**：可调节各相位模型的参数，实时观察焦散结构的变化
- **3D 可视化**：展示光线传播路径和焦散效果
- **观察面调整**：可调节观察面的位置、大小和可见性
- **光线采样控制**：可调节光线采样数量，平衡性能与效果
- **二维辅助视图**：提供相位分布、梯度场和光强分布的二维可视化，双击二维图可放大查看细节
- **交互式操作**：支持鼠标旋转、缩放和平移场景，支持点击数字并通过键盘输入控制参数

## 技术栈

- **核心框架**：React + Vite
- **3D 渲染**：Three.js, @react-three/fiber, @react-three/drei
- **状态管理**：Zustand
- **样式**：原生 CSS
- **参数 UI**：自定义 RangeInput 组件

## 使用环境

- **浏览器**：推荐使用 Chrome、Firefox、Edge 等现代浏览器
- **硬件**：需要支持 WebGL 2.0 的显卡
- **网络**：无网络依赖，可本地运行

在本地运行或构建项目之前，请确保您的开发环境已安装：

- **Node.js** (推荐版本 v18.0 或更高)
- **npm** (通常随 Node.js 一起安装)

您可以访问 [Node.js 官网](https://nodejs.org/) 获取安装包。安装完成后，可通过终端输入 `node -v` 验证

## 安装与运行

### 1. 克隆项目

```bash
git clone https://github.com/ShuxiLIU/caustics-sim.git
cd caustics-sim
```

### 2. 安装依赖

在项目根目录下运行（需联网）：

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

开发服务器启动后，在浏览器中访问 `http://localhost:5173/` 即可查看应用。

### 4. 构建与部署

```bash
npm run build
```

构建完成后，可将 `dist` 目录部署到任何静态网站托管服务。

## 界面说明

### 左侧栏
- **相位模型**：选择不同的相位函数
- **参数控制**：调整当前相位模型的参数

### 中央 3D 视口
- **相位参考平面**：半透明底面
- **相位类比曲面**：将相位分布抬升为可见网格
- **光线族**：从相位面出射的直线族
- **观察屏**：可沿 Z 轴平移，显示光线交点

### 右侧栏
- **观察面与采样**：调节观察面位置、大小和采样光线数
- **二维相位图**：显示相位分布的伪彩色图
- **相位梯度场**：显示梯度幅值和方向
- **拍摄效果**：显示观察面上的光强分布

## 键鼠交互操作

### 3D 视口交互
- **左键**：旋转场景
- **滚轮**：缩放场景
- **中键/右键**：平移场景
- **Shift + 左键**：平移场景

### 参数控制
- **拖动滑块**：调整参数值
- **点击数字**：通过键盘输入精确值
- **Enter**：确认输入

### 二维图交互
- **双击**：放大查看细节
- **点击模态框外部**：关闭放大视图
- **按 Escape**：关闭放大视图

## 物理模型

系统基于以下物理模型：
- **薄相位元件**：相位调制元件建模为位于参考平面上的薄元件
- **傍轴几何光学近似**：出射方向由相位梯度决定
- **自由空间传播**：光线沿直线传播到观察面
